Safer updates, a lighter privacy indicator and a dark mode shortcut, so antivirus tools have nothing to object to.

## Changed

* **Updates go through your browser.** When a new version is out, Settings › Updates (or the banner) opens the installer download in your browser, like any other download. Open it when it finishes to update; your settings stay. The island itself no longer downloads or runs programs.
* **Dark mode opens Windows' colour settings.** The Quick controls tile still shows whether dark mode is on; clicking it now opens the Windows page where you switch it, instead of the island changing Windows' theme settings itself. This was what Microsoft Defender reported as a "Settings Modifier" in 2.0.0.
* **Camera and microphone dots use Windows' activity reports only.** The island no longer watches the camera and microphone permission records in the registry, and it names apps from their process name without opening them.

Everything else is the same as 2.0.0.

## Install

Download `DynamicIsland-Setup-2.0.1-x64.exe` below (or `arm64` for ARM PCs) and run it. It upgrades 1.0 or 2.0 in place and keeps your settings.
